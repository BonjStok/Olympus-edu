# Презентация «Олимпус»

Презентация свёрстана как HTML-страница и собирается в PDF через Playwright (Chromium). Каждая
страница – 1920×1080 CSS px, в PDF это 1440×810 pt (16:9). 19 слайдов: технический, 17 содержательных
и источники.

```
presentation/
  deck.html                 слайды
  deck.css                  цвета, шрифты, слайд, шапка с вкладками, подвал с источником
  components.css            сетки, карточки, цифры, метки «Гипотеза», «Расчёт», «Наблюдение команды», сноски, таблицы
  blocks.css                телефон, чат MAX, QR, воронка, столбики, тепловая карта рисков
  pages.css                 раскладки отдельных слайдов
  deck.js                   шапка, телефоны, данные технического слайда и команды, QR, неразрывные пробелы
  TEXT.md                   полный текст всех слайдов для вычитки, собирается из deck.html при сборке
  NOTES.md                  текст выступления, вопросы и ответы, что сделать перед сдачей
  SOURCES.md                журнал проверки источников: утверждение → адрес → цитата → дата
  assets/fonts/             Inter 4.1 (OFL), собираются scripts/fonts.py
  assets/brand/             значок приложения, иконка в стиле «Сферума», Чатти – маскот «Сферума» (слайд 13)
  assets/team/              фото команды (не в Git, пути – в submission.local.json)
  assets/screens/           экраны приложения (JPEG 780×1688) и manifest.json
  submission.example.json   образец данных технического слайда и команды
  submission.local.json     настоящие данные (не в Git)
  scripts/build-pdf.mjs     сборка PDF и все проверки
  scripts/checks.mjs        проверки вёрстки и типографики внутри страницы
  scripts/style-rules.mjs   правила текста: штампы, отрицания, «от … до», тон серьёзной школы
  scripts/check-pdf.py      проверка готового PDF (PyMuPDF) и превью
  scripts/screenshots.mjs   пересъёмка экранов из запущенного приложения
```

## 1. Подготовка

```bash
pnpm install                          # из корня репозитория
pnpm exec playwright install chromium # если Chromium ещё не скачан
pip3 install pymupdf                  # по желанию, для проверки PDF
```

## 2. Данные технического слайда и команды

```bash
cp presentation/submission.example.json presentation/submission.local.json
```

Заполните в `submission.local.json` значения в угловых скобках: репозиторий, commit, пароли, состав
команды (`team[].name`, `role`, `org`, `photo`). Файл в `.gitignore`. Фото команды – квадратные
JPEG 360×360 в `assets/team/`, папка тоже в `.gitignore`; без фото на слайде будут инициалы. BOT_TOKEN в презентацию не выводится.
QR-код рисуется по `botUrl` через `npx --prefer-offline qrcode@1.5.4`: пакет берётся из кэша npm,
если он там есть.

## 3. Пересъёмка экранов

Запустите приложение с настоящими данными и выполните:

```bash
BASE_URL=http://localhost:3000 ADMIN_PASSWORD=… EVENT_ID=vsosh-tatarstan-math-2026-27 \
  node presentation/scripts/screenshots.mjs
```

Скрипт проходит интерфейс как ребёнок: первый экран, «Олимпиады», карточка, «Я участвую», урок,
задача, пробный тур (7 верных ответов из контента), «Главная», «Я», кабинет учителя и тёмная тема.
Экраны сохраняются в `assets/screens/<имя>.jpg`, список – в `manifest.json`. Переснять часть:
`ONLY=event,home`.

## 4. Сборка PDF

```bash
node presentation/scripts/build-pdf.mjs
# → presentation/dist/olympus-presentation.pdf
```

Сборка падает, если:

- не загрузились шрифты Inter или картинки;
- что-то выходит за край слайда, обрезано или текст прижат к краю;
- есть отладочная графика, размытые тени, фильтры или полупрозрачные заливки (в PDF-просмотрщиках
  они превращаются в серые прямоугольники);
- в тексте слайда есть длинное тире «—», обычный пробел перед «–», точка в конце абзаца, пункта,
  подписи или ячейки, одно слово в последней строке заголовка, контраст ниже WCAG AA;
- в тексте слайдов, `TEXT.md` или `NOTES.md` есть штампы и приёмы из `scripts/style-rules.mjs`
  (метафоры вроде «мостик», «не X, а Y», усилители, упоминания ТЗ и организаторов хакатона) или
  абзац заканчивается точкой.

Неразрывные пробелы после чисел и коротких слов, перед «–» и в конце заголовков расставляет
`deck.js`. Потом `scripts/check-pdf.py` проверяет PDF: размер страниц, встроенные шрифты,
непрозрачные заливки. Превью для просмотра:

```bash
python3 presentation/scripts/check-pdf.py presentation/dist/olympus-presentation.pdf --previews /tmp/deck-preview
```

## 5. Как поправить текст или цифры

- Текст и цифры – в `deck.html`; `TEXT.md` обновится сам при сборке.
- Проверенный источник: `<sup class="ref">N</sup>` на слайде, строка на слайде 19 и в `SOURCES.md`.
- Утверждение без внешнего источника – только с меткой (см. ниже) и строкой в конце `SOURCES.md`.
- Метки: `<span class="tag hyp">Гипотеза</span>`, `tag calc` – расчёт, `tag obs` – наблюдение или
  оценка команды.
- Правила оформления проверяет сборка: только синий, фиолетовый, голубой, бирюзовый и серый;
  формулировки без отрицаний и без «от … до»; «пробные олимпиады» вместо «пробных туров»;
  строка источников ни с чем не пересекается.
- После правок: `pnpm exec prettier --write presentation`.
